# 高职 / 职业大学招生合作一页纸

**产品**：未来探索者（TureCareer Explorer）  
**定位**：游戏化性格测试 + 可核验的职业教育院校/专业推荐  
**数据依据**：教育部《全国普通高等学校名单》（截至 2026-06-17）

---

## 你们能得到什么

1. **招生转化工具**：3 分钟完成测试，生成可分享结果图，适合班级活动与招生活动现场。
2. **可核验院校推荐**：推荐校名对齐官方名单，并标注专科 / 本科（含职业本科）层次，降低家长质疑。
3. **省份优先**：学生可按所在省份筛选，优先看到本省相关院校。
4. **可选白标试点**（下一阶段）：落地页标题/Logo 定制、班级汇总报告导出。

---

## 建议试点省份（专科院校密度高）

河南、山东、江苏、湖南、广东；城市试点可优先：重庆、广州、郑州、长沙。

## 合作方式（草案报价，可谈）

| 套餐 | 内容 | 参考报价 |
|---|---|---|
| 活动试用 | 1 次招生活动页 + 结果页引导到贵校咨询 | 免费–试用 |
| 学期班级包 | 班级测评入口 + 汇总反馈口径 | 800–3000 元/学期 |
| 年度合作 | 品牌露出 + 持续活动支持 + 线索对接 | 0.8–5 万/年 |

## 合规说明

- 产品为升学参考工具，**非心理诊断**。
- 院校信息以教育部公开名单为准，录取以各校招生章程为准。
- 不承诺录取结果或就业薪资。
